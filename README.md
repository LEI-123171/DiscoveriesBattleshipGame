## ⚓ Sobre o Projeto

**Batalha Naval — Descobrimentos** é uma adaptação do clássico jogo Batalha Naval, inspirada na época dos Descobrimentos.

Neste jogo, dois jogadores posicionam estrategicamente as suas frotas e tentam descobrir a localização dos navios adversários. O objetivo é **afundar toda a frota inimiga antes do adversário**.

## Regras do Jogo

1. **Grelha e Posicionamento**
   * O jogo é jogado numa grelha de **10x10** para cada jogador.
   * Os navios são posicionados na **horizontal ou vertical**, sem que se possam tocar entre si em nenhuma direção (embora possam encostar às bordas do tabuleiro).

2. **Desenrolar das Jogadas**
   * Os jogadores jogam à vez.
   * Em cada turno, o jogador atira uma **rajada de 3 tiros**, indicando as respetivas coordenadas `(linha, coluna)`.
   * O adversário deve reportar o resultado dos 3 tiros, informando quantos foram na **água**, quantos **atingiram navios** (e de que tipo) e se algum navio foi **afundado**.

3. **Objetivo e Vitória**
   * Ganha o primeiro jogador que conseguir **afundar a totalidade da frota adversária**.
